# Lenz

Lenz is inspired by Lenz’s law. Its mark uses two opposing L forms. The physics reference is visual inspiration, not a security argument.

**Talk privately. Use DeFi without internet.**

The mark keeps the forest, paper and lime palette. It has rounded endpoints and an open centre. The wordmark uses Segoe UI with an Arial fallback. The descriptive line expresses the product ambition; the app distinguishes testnet tUSD from earlier synthetic demo assets.

Generate SVGs with `node brand/generate.mjs`, then PNGs with `node brand/render.cjs`. The latter uses sharp on NODE_PATH. `node brand/verify.cjs` checks exports and responsive pages using Playwright and installed Edge. Windows emitted nonfatal font-cache warnings during raster export; the resulting images were inspected.


Lenz is the selected name. Trademark, domain and handle availability have not been cleared. Proof of U remains in protocol identifiers and historical research; the separate proof name is undecided.
