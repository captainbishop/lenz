# Lenz visual identity

The Lenz mark consists of two opposing rounded L forms with an open centre. The product descriptor is **Talk privately. Use DeFi without internet.** Proof of U remains the protocol namespace.

## Palette

| Colour | Value | Use |
| --- | --- | --- |
| Forest | `#173F35` | Wordmark, main actions and strong surfaces |
| Paper | `#F5F5EF` | Light backgrounds and reverse text |
| Seed | `#E1EFA6` | Accent and primary actions on forest |
| Moss | `#52665B` | Supporting text on paper |

## Typography and assets

The wordmark uses Segoe UI or Arial semibold. Short editorial headings use Georgia; functional text uses Segoe UI or Arial. Fonts and assets are local so the interface can work offline.

SVG masters retain their original proportions. Clear space is at least one quarter of the mark's width. The app mark has a minimum size of 24 px; dedicated app icons cover smaller favicon sizes. Monochrome variants support single-colour use.

## Interface

The layout uses a 4/8 px spacing scale, 16 px reading text and 44 px controls. Keyboard focus remains visible. Hover feedback is brief, and motion respects reduced-motion preferences. Homepage recordings demonstrate the documented product flows in light and dark themes.

The descriptor expresses the product ambition. Screens identify test assets, pending settlement and privacy limitations; a brand statement is not evidence of an implemented guarantee. Trademark, domain and handle availability have not been cleared.
