# Financial recovery review

Wallet settings opens Financial recovery. Read retained records lists validated
private approvals, public wallet attempts, signed test-dollar funding/transfers,
Rhea reservations, prototype reservations and supported Hyperliquid orders or
cancellations. Exact owner, asset, nonce, input and local evidence hashes are in
Details. Unknown or unreadable stores remain explicit evidence gaps.

Save review keeps a separate encrypted copy. Review files can download or merge
an encrypted copy with the same Lenz account keys. A device-only account still
needs its original keys; this file alone cannot recover them. An older copy
cannot remove saved evidence, resolve a conflict or enable spending. Copies are
merged as retained observations, without authoritative freshness claims.

The review writes no balances, permissions, transactions or reservations.
Every review stays unreconciled and cannot execute. Device wallet journals do
not authenticate a wallet owner to a Lenz ID. Encryption authenticates the same
key holder; it does not authenticate funding, chain finality or archive age.

Canonical funding/outcomes, executor journals, other devices, spending epochs,
financial keys, bounded budgets, Zcash restore/rescan and unsupported venues
remain missing. Complete financial restoration and exclusive spending recovery
require those separate mechanisms.
