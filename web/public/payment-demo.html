A FIRST WORKING SLICE

Offline use. Honest boundaries.

Lenz is a web-first project for offline DeFi and private conversations. This page contains the original Proof of U payment experiment. This is a single-browser workspace with three demo people. It creates and checks real PLONK step proofs, encrypts handovers, and supports onward transfers.

  1. Prepare the offline demo while connected.
  2. Send a payment, then switch to its recipient.
  3. Receive it and pass it onward, with the network disconnected.

Demo keys and balances live in this browser’s local storage. They are test data, not a secure wallet for real funds. Exported files only work in this workspace.

This earlier experiment does not settle on a blockchain. The current Wallet and Conversations pages support funded tUSD settlement and Rhea swaps on NEAR testnet. Separate Zcash test tools support a native shielded transfer and unsigned browser review; Zcash signing in the browser, private NEAR settlement and safe recovery remain open. Final settlement needs a connection. Native Android and iPhone apps are on the roadmap.
